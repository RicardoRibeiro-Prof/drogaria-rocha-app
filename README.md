# Drogaria Rocha — PWA de pedidos

Primeira versão funcional e instalável para validar pedidos pelo celular.

## O que já funciona

- catálogo com pesquisa e categorias;
- carrinho persistente no aparelho;
- inclusão e remoção de quantidades;
- entrega ou retirada;
- captura/seleção de receita (imagem ou PDF de até 8 MB);
- compartilhamento estruturado do pedido e da receita pelo celular;
- alternativa pelo WhatsApp em navegadores sem compartilhamento nativo;
- instalação como PWA e funcionamento básico offline.

## Executar

```bash
npm install
npm run dev
```

## Gerar versão final

```bash
npm run build
```

## Dados que precisam ser substituídos antes da publicação

1. Logo oficial e cores, caso a Drogaria Rocha já possua identidade visual.
2. Catálogo, preços, estoque e categorias reais.
3. Endereço, horários, área de entrega e telefone oficial.
4. Política de privacidade e responsável pelo tratamento de dados.
5. Regras operacionais aprovadas pelo farmacêutico responsável.

Os produtos e preços atuais são apenas demonstrativos. Esta versão não realiza venda automática de medicamento controlado nem promete disponibilidade antes da confirmação humana.
