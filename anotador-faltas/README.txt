ANOTADOR DE FALTAS — DROGARIA ROCHA

COMO USAR
1. Abra o arquivo index.html no Google Chrome ou Microsoft Edge.
2. Deixe a tela aberta.
3. Passe um produto no leitor USB de código de barras.
4. O leitor deve estar configurado para enviar ENTER após o código.
5. O produto será incluído automaticamente na lista.
6. Ao passar novamente o mesmo código, a quantidade aumenta.

TESTE SEM LEITOR
Abra "Teste sem leitor" e use um destes códigos de demonstração:
- 7890000000011 = Dipirona 500mg
- 7890000000028 = Paracetamol 750mg
- 7890000000035 = Losartana 50mg

PRODUTO NÃO CADASTRADO
O sistema não interrompe a anotação. O código entra na lista como "Produto não cadastrado".
Depois, clique em "Cadastrar produto", informe o mesmo EAN e o nome. A lista será atualizada automaticamente.

DADOS
Nesta versão básica, os cadastros e a lista ficam salvos no navegador (localStorage).
Não há login, servidor nem banco de dados externo.
